# Пробный голос Капри

Это отдельный модуль озвучивания. Выбранный вариант пользователь оценил как более близкий к Капри. Он синтетический и не обещает точного совпадения с актёрской озвучкой. Капри продолжает говорить по-русски, хотя образец взят из английской речи.

Обычный разговор остаётся через выбранный API. Этот модуль занимается только голосом: локальная разговорная модель не устанавливается, API-ключ для озвучивания не нужен.

## Как включить

1. Распакуй папку `voice-backend-qwen` рядом с EXE Капри.
2. Открой `install-voice.cmd` двойным щелчком. Нужны интернет и свободное место: голосовая модель и её окружение занимают несколько гигабайт. Дождись окончания, не закрывая окно.
3. Запусти Капри и выбери в её меню пробный голос Капри. Если приложение найдёт установленный модуль рядом, оно запустит его само.

Если Капри не запустила модуль автоматически, открой `start-voice.cmd` и оставь его окно работающим. Для остановки закрой это окно. `start-voice-offline.cmd` запускает тот же режим без обращений за моделью в интернет.

Оригинальный образец должен находиться в `%APPDATA%\CapriCompanion\capri-approved-reference.audio`. Приложение сохраняет туда подтверждённую запись отдельно от старых экспериментов. Если образца нет, модуль сообщает об этом, а Капри может использовать запасной голос Windows.

## Чего ждать от скорости

Первая новая фраза готовится на процессоре. На тестовом компьютере фраза длиной 2,64 секунды потребовала около 24 секунд синтеза; загрузка уже скачанной модели — ещё около 10 секунд. На другом ПК время может отличаться.

Повторные фразы сохраняются в локальном аудиокэше и воспроизводятся гораздо быстрее. Их можно использовать без повторной загрузки большой модели. Тексты не записываются в журнал; файлы кэша имеют служебные имена.

Готовые короткие реплики в самом приложении могут звучать сразу. Для произвольного нового ответа задержка остаётся. Во время игры модуль по умолчанию использует только два потока CPU.

## Где лежат файлы

По умолчанию установщик создаёт папку `.tools\capri-qwen-voice` рядом с папкой модуля. Там находятся собственный Python 3.11, зависимости, модель и аудиокэш. Системный Python, PATH, драйверы и автозагрузка Windows не меняются.

Чтобы выбрать другую папку, открой PowerShell в папке модуля и выполни:

```powershell
.\install-voice.ps1 -RuntimeDirectory 'D:\CapriVoiceRuntime'
```

Для ручного запуска из этой папки:

```powershell
.\start-voice.ps1 -RuntimeDirectory 'D:\CapriVoiceRuntime'
```

Автоматический поиск в Капри рассчитан на обычную папку `.tools\capri-qwen-voice`. Для нестандартного размещения можно пользоваться ручным запуском.

## Для разработки

Сервер слушает только `127.0.0.1:8795`. `GET /health` возвращает состояние; `POST /tts` принимает JSON `{"text":"Привет","voice":"capri"}` и возвращает WAV. Без образца или модели возвращается понятная ошибка. При обычном запуске `--offline` загрузка весов из интернета запрещена; установщик скачивает их отдельно через `--download-only`.

Используется Qwen3-TTS-12Hz-1.7B-Base, ревизия `fd4b254389122332181a7c3db7f27e918eec64e3`, режим speaker-only без английской расшифровки. Веса имеют лицензию Apache 2.0. Все зависимости закреплены в `requirements.lock`; источники перечислены в `SOURCES.md`.

`preview.py` и `transcribe_reference.py` сохранены как инструменты эксперимента. Они не запускаются обычной Капри.
