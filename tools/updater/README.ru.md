# Обновление Капри без повторной загрузки голоса

`Capri-Update.exe` содержит только новый стартовый EXE приложения. Он не использует интернет, не содержит Python или голосовую модель и не читает личный профиль `%APPDATA%/CapriCompanion`.

Для получателя:

1. Закрой старую Капри: правой кнопкой по персонажу → «Выйти».
2. Открой `Capri-Update.exe`. Если старая папка не найдена автоматически, нажми «Найти папку…» и выбери папку, где находится `Запустить Капри.exe`.
3. Нажми «Обновить». Капри запустится после завершения, если оставить галочку включённой.

Для следующих запусков открывай `Запустить Капри.exe` в этой папке. Старый загрузчик `Capri-Download.exe` закреплён на прежней сборке и после обновления может попросить другую папку; повторно скачивать комплект для обновления не нужно.

Обновляется `Запустить Капри.exe`, строка этого EXE и номер версии в `bundle-manifest.json`; добавляется `.capri-update.json` с версией и контрольной суммой нового EXE. Скачанные модель, Python, модуль озвучивания, голосовой кэш и прочие пользовательские файлы не заменяются. `.capri-installed.sha256` сохраняет исходную контрольную сумму базового архива.

Предыдущий EXE сохраняется рядом как `Запустить Капри.previous.exe`. Уже существующая резервная копия сохраняется, а новая получает отдельное имя. При обычной ошибке до завершения короткой транзакции EXE и служебные файлы автоматически возвращаются к предыдущему состоянию.

В папке должен быть оригинальный `capri-ready.json`, манифест и установленный голосовой модуль. Обновлятор не создаёт новую установку и не меняет произвольные папки. Если Капри работает или её EXE заблокирован, обновление просит закрыть приложение; чужие процессы не завершаются. Повторное применение того же обновления не создаёт ещё одну копию старого EXE.

## Сборка

Требуется Windows с .NET Framework 4.8 и встроенным C# compiler. Выполнять из этой папки:

```powershell
.\build.ps1 -AppExePath 'C:\CapriBuild\Capri-Companion-0.4.4-companion.9-win-x64.exe' -Version '0.4.4-companion.9' -OutputPath 'C:\CapriBuild\Capri-Update.exe'
```

Сборка встраивает EXE как ресурс, фиксирует его размер и SHA-256. Итоговый файл примерно на 190 КБ больше встроенного EXE; голос в него не входит. Нужен запас свободного места около размера EXE плюс 64 МБ, а одна предыдущая версия остаётся в резервной копии.

```powershell
.\test.ps1
```

Тесты проверяют повреждение и отмену, отказ от замены работающего и заблокированного EXE, точное обнаружение собственного процесса, откат после каждого этапа транзакции, сохранение голоса и сторонних файлов, существующую резервную копию, повторное обновление, определение папки и отказ при неизвестных маркере или манифесте. Сетевого кода, удаления папок и изменения системных настроек нет.
