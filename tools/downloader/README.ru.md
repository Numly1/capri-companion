# Один запуск готовой Капри

Небольшой загрузчик для публичного GitHub Release. Пользователь скачивает один EXE. При первом запуске он автоматически скачивает три части проверенного готового архива, проверяет SHA256 частей и всего ZIP, распаковывает папку и запускает Капри. Отдельная установка Python или голосовой модели не нужна.

Папка по умолчанию: `%LOCALAPPDATA%\CapriReady\Капри`. Её можно изменить кнопкой «Другая папка…». Выбор сохраняется, в том числе после отмены. При повторном запуске готовая установка открывается без сетевых запросов. Настройки самой Капри и API-ключи этот загрузчик не читает и не меняет.

Цель: Windows 10/11 с .NET Framework 4.8. Первое скачивание — около 4,2 ГБ; до начала проверяется наличие 11 ГиБ свободного места для загрузки и распаковки. Комплект занимает около 5,7 ГБ после распаковки. Существующая чужая папка «Капри» не заменяется. Отмена сохраняет завершённые части; незавершённая часть скачивается повторно.

Загрузчик принимает только HTTPS GitHub и обычные перенаправления на GitHubusercontent. Адрес релиза и контрольные суммы встроены при сборке. Из командной строки и переменных окружения адрес загрузки изменить нельзя. Сборка не содержит API-ключей.

## Сборка

Нужен штатный C# compiler .NET Framework. Скачайте `capri-ready-manifest.json` из того же GitHub Release. `build.ps1` проверяет его размеры, контрольные суммы полного архива/стартового EXE и принимает owner, repo и tag. Манифест содержит все три части:

```json
{"archiveBytes":4199165651,"archiveSha256":"...SHA256 полного архива...","unpackedBytes":5722450647,"launcherSha256":"...SHA256 стартового EXE...","parts":[{"name":"capri-ready-win-x64.zip.part01","bytes":1800000000,"sha256":"...SHA256 части..."}]}
```

В реальном манифесте должны быть все три части, каждая не больше 1,8 ГБ; суммарный размер этой версии — 4199165651 байт. SHA256 целого архива и стартового EXE закреплены в `build.ps1`. Для нового комплекта их необходимо обновить по фактическим проверенным файлам.

```powershell
.\build.ps1 -Owner 'Numly1' -Repo 'capri-companion' -Tag 'v0.4.4-companion.8' -ManifestPath 'capri-ready-manifest.json' -OutputPath 'Capri-Download.exe'
```

Сборка создаёт один самостоятельный EXE. `BuildInfo.generated.cs` генерируется из проверенных параметров. Иконка автоматически ищется выше папки скрипта в `app/assets/icons/capri.ico`; также можно передать `-IconPath 'путь\capri.ico'`. Поэтому сборка работает и из публичной папки `tools/downloader`. Локальные бинарники в `compile-only` — тестовые, публиковать их нельзя.

## Проверки

`test.ps1` собирает отдельный консольный тест с локальным HTTP-сервером. Проверены скачивание частей, SHA256, объединение, кириллица в ZIP, пути длиннее 260 символов, обход путей ZIP, отмена сетевого чтения, повторный запуск без сети, повторное использование готовой части, учёт оставшегося места при продолжении и сохранность существующей папки. Зависшая сеть прекращает загрузку после 90 секунд без данных; пользователь может повторить попытку.

Локальный HTTP разрешён только при компиляции `TEST_BUILD`; такой код отсутствует в публикуемом EXE. `Preview.cs` — отдельная проверка внешнего вида с `PREVIEW_BUILD`, без автоматической загрузки. Обычная сборка не включает эти файлы и флаги.

Дополнительно через этот же .NET-распаковщик проверен полный исходный архив: 30 339 файлов, 5 722 450 647 байт, около 70 секунд. SHA256 стартового EXE, portable Python и файла модели размером 3,85 ГБ после распаковки совпали с манифестом. Полная загрузка 4,2 ГБ из опубликованного релиза проверяется после публикации. На чистой Windows VM эта версия загрузчика не проверялась.
