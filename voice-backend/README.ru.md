# Дополнительный локальный голос

Этот модуль озвучивает русские ответы по короткому образцу голоса. Он не требует API-ключа. Нужен отдельный аудиофайл с чистой речью персонажа: желательно 6–10 секунд без музыки и других голосов. Сходство зависит от записи; точную копию актёрской озвучки модель не гарантирует.

Обычная Капри работает и без этого модуля: при его отсутствии приложение использует голос Windows.

## Как включить на этом компьютере

1. Импортируй запись через настройки Капри. Файл сохраняется локально в `%APPDATA%\CapriCompanion\voice-reference.audio`.
2. Открой `start-voice.cmd`. Оставь открывшееся окно работающим.
3. Выбери голос по записи в настройках Капри. Язык ответов остаётся русским.

Первый запуск модуля скачивает несколько гигабайт публичных весов и загружает их в память. Затем модель работает локально. На процессоре ответ может озвучиваться с заметной задержкой. По умолчанию модуль использует два потока CPU, чтобы не занимать видеопамять игры. Модель остаётся в памяти между фразами.

На этом компьютере короткая тестовая фраза длительностью 1,76 секунды потребовала около 37 секунд синтеза на CPU; первоначальная загрузка уже скачанной модели — около 35 секунд. Это дополнительный режим для качества и настройки тембра. Мгновенной речи во время игры он не даёт.

После первой успешной загрузки можно пользоваться `start-voice-offline.cmd`: он запрещает обращения к серверу моделей и использует скачанные файлы.

Повторные фразы сохраняются как WAV в `voice-cache` приватного окружения. Уже подготовленная реплика воспроизводится без повторного синтеза и без загрузки большой модели. Кэш разделён по содержимому образца, тексту и параметрам голоса; при смене образца чужой тембр не используется. Ограничение — 128 записей и 128 МБ. Для новых фраз задержка CPU остаётся.

Первый экспериментальный образец из присланного видео (03:23,3–03:31,6) дал русскую речь, но пользователь отклонил её как непохожую. Этот вариант не подключается автоматически. Короткий фрагмент сведённой дорожки и межъязыковой синтез пока не обеспечили нужный тембр; точный голос ещё настраивается.

Закрой окно модуля, чтобы освободить память. Капри сможет продолжить обычную озвучку Windows.

## Установка на другом компьютере

Открой `install-voice.cmd` и дождись окончания. Установка создаёт собственный Python 3.11 и окружение в `.tools\capri-voice` рядом с папкой модуля. Системный Python, PATH и драйверы не меняются. Нужны интернет и несколько гигабайт свободного места. После установки открой `start-voice.cmd`.

Если файлы устанавливаются в другое место, запусти PowerShell:

```powershell
.\install-voice.ps1 -RuntimeDirectory 'D:\CapriVoiceRuntime'
```

Для такого пути запусти модуль напрямую из установленного окружения:

```powershell
& 'D:\CapriVoiceRuntime\venv\Scripts\python.exe' '.\server.py' --runtime 'D:\CapriVoiceRuntime' --device cpu
```

## Для разработки

Локальный сервер слушает только `127.0.0.1:8794`. Он не записывает тексты запросов в журнал. `GET /health` возвращает состояние и наличие записи; `POST /tts` принимает JSON `{"text":"Привет","voice":"capri"}` и возвращает WAV. Без записи возвращается `503 reference_missing`, без попытки загрузить модель.

`--reference` позволяет задать другой файл. WAV, MP3, OGG и FLAC читаются по содержимому, поэтому расширение `.audio` не мешает. Скрипт `import_reference.py` отдельно сохраняет выбранный 3–15-секундный фрагмент в моно WAV; исходник сохраняется.

`check_engine.py` проверяет загрузку модели и русскую речь встроенным голосом. Этот тестовый голос не является голосом Капри.

PyPI-пакет 0.1.7 на момент проверки не имел аргумента `t3_model`, поэтому используется закреплённый официальный исходный код. Все зависимости записаны в `requirements.lock`. Веса скачиваются из [ResembleAI/chatterbox](https://huggingface.co/ResembleAI/chatterbox). В генерируемом аудио сохраняется штатный водяной знак PerTh.
