# Capri Companion для Windows

В готовом комплекте «Капри-всё-готово.zip» достаточно распаковать папку «Капри» и открыть «Запустить Капри.exe». Интерпретатор, зависимости и одобренная модель голоса входят в комплект и работают локально без установки или загрузки. При первом запуске такого комплекта версия 8 включает пробный голос автоматически, сохраняя API-ключи и остальные настройки существующего профиля. Последующие ручные изменения голоса сохраняются. Для свободного диалога через API ключ вводится отдельно в приложении.

Личная некоммерческая версия [Capri Desktop](https://github.com/mochiiwuff/capri-desktop) автора **mochiiwuff**, дополненная режимом компаньона. Сохранены персонаж и анимации исходного приложения: появление, полёт, телепортация, реакции, сон и взаимодействие с окнами.

Карточка Spotify показывает локальную обложку, исполнителя и прогресс трека. Её видимость и голосовые реакции на музыку настраиваются отдельно в меню Spotify. Ключ Spotify не требуется; при отсутствии обложки в данных Windows показывается нота. Изображение обложки и шкала времени не включаются в запросы разговорного ИИ.

Версия 7 отделяет одобренный голос Капри от старого эксперимента Chatterbox. Кнопка «Голос» больше не выбирает старый эксперимент, а подсказка показывает текущий тембр. Выбранный пробный голос не подменяется Windows при ошибке модуля: причина показывается в диалоге.

Язык ответов о снимках экрана теперь закреплён отдельной настройкой: русский по умолчанию. Английские надписи, внутренние команды и выбранный тембр не переключают ответ на английский.

## Запуск и подарок

Откройте `Capri-Companion-…-win-x64.exe`. Это portable-сборка: отдельный установщик, Node.js и Electron получательнице не нужны. Для варианта в ZIP распакуйте всю папку и запустите находящийся внутри `Capri-Companion-…-win-x64.exe`.

Эта версия называется **Capri Companion** и использует отдельные настройки, чтобы не смешивать их с исходной Capri Desktop. Для подарка передайте готовый EXE или ZIP и этот файл. Личные настройки и API-ключи передавать не нужно.

## Обычный режим

По умолчанию Капри работает без API-ключа: короткие реплики, локальные ответы и поддерживаемые команды. Эти ответы написаны заранее и не являются свободной генерацией ИИ. Режим ИИ включается отдельно в настройках.

Spotify и Krita настраиваются отдельными пунктами меню: каждый источник имеет свой переключатель и свой интервал. Комментарии не идут чаще одного в минуту суммарно. Дополнительные движения и гличи имеют три режима и пропускаются, пока открыт диалог или персонаж занят.

В Krita первая реплика поддержки появляется после 90 секунд непрерывного рисования на переднем плане. Дальше похвала повторяется с заданным интервалом, по умолчанию 12 минут, с чередованием фраз. Реплики относятся к старанию, а не к невидимым персонажу деталям картины.

Фоновые реплики озвучиваются и во время обычных прогулок. Добавлены 36 русских и 8 японских реплик, расширены готовые ответы. Фоновая речь имеет отдельный переключатель и паузу, по умолчанию 5 минут; она пропускается во время игры, разговора, записи, сна и другого воспроизведения. Настройки ключа, OCR и системные ошибки не озвучиваются как случайная болтовня.

SS14 / Arcane Nirvana: отдельный локальный наблюдатель читает только активное окно клиента, проверяет знакомые видимые объявления об уровне угрозы, эвакуации, конце раунда и потере соединения. Проверка каждые 20 секунд, реакция по умолчанию не чаще раза в 3 минуты. Скрытые роли и события вне экрана не анализируются; сырой OCR не передаётся в renderer, историю или API. Правила сверены с публичной локализацией Arcane; живой раунд пока не проверялся.

Minecraft Java: локальная интеграция использует новые сообщения клиентского лога активной игры. Путь можно определить по запущенному клиенту или выбрать вручную. Содержимое мира и скрытые игровые данные не читаются.

Во время активной игры Капри остаётся видимой и не уходит в автоматический сон. Сворачивание в играх включается отдельно в меню. Ручное скрытие пользователя не отменяется игровым наблюдателем.

Для анализа изображений есть отдельная настройка модели просмотра экрана. Обычный разговор может оставаться на GPT-OSS, а снимки обрабатываться доступной vision-моделью того же сервиса. Автоматический выбор исключает известные текстовые модели Groq; на этом аккаунте проверена обработка служебной картинки через qwen/qwen3.8-27b. Пользовательские снимки в этой проверке не использовались.

Настройка API различает отказ доступа 403, неверный ключ 401 и отсутствие соединения. При 403 приложение предлагает диагностику и выбор другого сервиса вместо бесконечного запроса того же ключа. Само ограничение внешнего сервиса приложение снять не может.

Пункт «Посмотреть экран · без ИИ» однократно читает видимый текст через Windows OCR. Изображение существует только в памяти. Результат не сохраняется в истории чата и не отправляется облачной модели. Это распознавание надписей, а не анализ сюжета или композиции рисунка.

Явная команда «найди …» открывает браузер с поисковым запросом. Подключать инструменты для программистов ради обычного общения не требуется. Скрипты `hooks:install`, `hooks:codex:install` и другие установщики интеграций в этой сборке автоматически не запускаются.

## ИИ по желанию

Для свободного разговора включите ИИ и укажите сервис, доступную модель и, если требуется, собственный API-ключ. Использование внешнего API может оплачиваться отдельно. Ключ вводится в приложении; не присылайте его в чат и не включайте в подарок.

В обычном режиме облачная модель не вызывается автоматически. При включённом ИИ сообщения отправляются выбранному сервису после отправки в диалоге. Отключение ИИ возвращает локальные ответы.

## Голос

Доступность голосового ввода и озвучивания зависит от установленных компонентов Windows и подключённого сервиса. Если голос или распознаватель на нужном языке недоступен, текстовый диалог остаётся доступен. Не предполагается постоянное прослушивание микрофона.

Синтетический голос и локальные голоса Windows не являются оригинальной озвучкой персонажа или голосом актрисы. Приложение не создаёт точную копию оригинального голоса по названию персонажа.

Добавлен выбранный пользователем пробный тембр «Капри · пробный голос» на Qwen3-TTS 1.7B speaker-only. Одобренная проба и четыре коротких фоновых реплики встроены в EXE; суммарно все WAV, включая образец, занимают менее 1 МБ. Они воспроизводятся без Python и без модели. Сохранённый звук не проходит цифровое повышение тона и хор Windows.

Новые тексты до 400 символов обрабатывает отдельный модуль `voice-backend-qwen` на `127.0.0.1:8795`. Он автоматически запускается, если установлен рядом, работает локально на двух потоках CPU и сохраняет повторные фразы в кэш. В проверке нового предложения потребовалось 39,8 с с загрузкой модели; повтор — около 8 мс. Для более длинного ответа озвучивается одно короткое начало до 160 символов с явным пояснением; полный ответ остаётся в тексте. Ошибка модуля, занятость и тайм-аут показываются отдельно, без автоматической подмены выбранного тембра на Windows. Качество произношения и сходство остаются экспериментальными.

Разговорный ИИ остаётся через API. Установка этого голосового модуля отдельно требует нескольких гигабайт; голоса Windows и пять встроенных записей доступны без неё.

Кнопка «Голос» в разговоре переключает цифровое, звонкое и обычное звучание. Язык ответов задаётся отдельно и по умолчанию остаётся русским. Цифровой вариант использует локальный голос Windows, повышение тона и тихий хор из двух дополнительных слоёв. Синтез не расходует API.

Для прежнего экспериментального голоса по образцу сохранён отдельный локальный модуль `voice-backend` на Chatterbox Multilingual V3. Его большая модель не включена в portable EXE. После установки модуля импортируйте чистую запись через «Выбрать голос» → «Старые эксперименты · Chatterbox» → «Загрузить образец голоса…». Модуль принимает запросы только на `127.0.0.1:8794`, выдаёт русскую речь и не использует API-ключи. При недоступном модуле старый эксперимент возвращается к Windows с пояснением.

Подробная инструкция без терминала: `КАК ПОЛЬЗОВАТЬСЯ КАПРИ.txt` рядом с приложением. Для свободного разговора в меню есть «Подключить Groq Free…». Ключ ещё нужно создать в своём аккаунте и ввести в Капри; в сборку ключи не включены. Проверка живого API без ключа не выполнялась.

## Сборка из исходников

Нужен Node.js версии 22.12 или новее (здесь проверен Node.js 24.16). Команды выполняются из папки `app`:

```powershell
npm ci
npm start
npm run dist:portable
```

Команда `npm ci` может выполнять скрипты зависимостей; в подготовке этой версии зависимости устанавливались через `npm ci --ignore-scripts`, а Electron загружался отдельно из официального релиза. Установщики интеграций с Claude, Codex и другими инструментами — отдельные команды, для сборки они не нужны.

Результат portable-сборки: `dist/companion` в корне проекта. `npm run dist:dir` создаёт распакованное приложение для ручной проверки и ZIP.
