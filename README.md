# Капри для рабочего стола

Анимированная спутница для Windows: живёт поверх окон, разговаривает голосом и текстом, реагирует на Spotify, Krita, Minecraft и Space Station 14.

## Скачать и запустить

**Капри уже скачана? [Обновить без повторной загрузки голоса](https://github.com/Numly1/capri-companion/releases/latest/download/Capri-Update.exe)** — примерно 116 МБ вместо нескольких гигабайт. Закрой старую Капри через «Выйти», запусти обновление и нажми «Обновить». Если папка не найдена автоматически, выбери прежнюю папку с Запустить Капри.exe. Голос, API-ключ и переписка сохранятся. Затем запускай прежний EXE в этой папке.

**[⬇ Скачать Капри](https://github.com/Numly1/capri-companion/releases/latest/download/Capri-Download.exe)**

Открой скачанный `Capri-Download.exe`. Он сам подготовит готовую папку с голосом и запустит Капри. Команды, Python и отдельные установщики не нужны. При необходимости выбери папку на другом диске кнопкой в окне загрузки.

Первая загрузка — около **4,2 ГБ**. Готовая папка занимает **5,7 ГБ**; во время подготовки нужно примерно **11 ГБ** свободного места. Повторный запуск подготовленной Капри ничего не скачивает: открой `Капри/Запустить Капри.exe`.

## Как пользоваться

- Перетащить: зажми персонажа левой кнопкой мыши.
- Меню и разговор: нажми по Капри правой кнопкой.
- Спрятать или вернуть: `Ctrl + Alt + C`.
- Голос уже включён. Новые фразы на процессоре готовятся с задержкой; записанные и повторные реплики звучат быстрее. У длинных ответов озвучивается короткое начало, а полный ответ остаётся текстом.

Готовые реплики, анимации, реакции на программы и локальное чтение надписей с экрана работают без облачного ИИ. Для свободного диалога один раз подключи доступный API и введи свой ключ в Капри. Ключи и чужая переписка в комплект не входят. Поддержка конкретного сервиса зависит от доступа аккаунта и подключения.

В Spotify видны обложка, исполнитель и прогресс трека. Для Krita есть отдельные похвалы с паузами. Minecraft использует новые события клиентского лога; SS14 — локальное распознавание видимых объявлений. Понимание изображения экрана требует отдельного включения облачного анализа.

## Исходники и сборка

Новое в версии 0.4.4-companion.9:

- «Экран»: закрепление за выбранным монитором. Временное отключение монитора не сбрасывает выбор.
- «Во время игры»: оставаться рядом, спать или прятаться; задержка и выбор игр задаются отдельно. Автоматический сон заканчивается после переключения из игры.
- Discord Rich Presence: Капри, текущая игра или просмотр. Выключен до настройки публичного Application ID собственного приложения в [портале Discord](https://discord.com/developers/applications). Токен аккаунта не нужен; используется настольный Discord и локальный IPC. Название игры и просмотра отключается отдельным переключателем.
- «Смотрим вместе · Кинопоиск»: редкие локальные реплики без спойлеров. Автоматический режим ждёт подтверждённого воспроизведения, ручной помогает браузерам без media session. Кадры и сюжет эти реплики не анализируют.
- Дополнительные события SS14: метеориты, ионный шторм, утечка газа, солнечные вспышки, питание; поддержка и передышка из меню, одна отключаемая реплика об ЕРП.

Первый комментарий к просмотру — после двух минут; пауза по умолчанию 12 минут. Сон, игра или разговор подавляют комментарии без отложенной очереди. Код небольшого обновления находится в tools/updater. Новый загрузчик первого запуска использует проверенный голосовой комплект из релиза 8 и добавляет актуальное приложение. Для уже установленной Капри передавай Capri-Update.exe.

Приложение находится в `app/`, модуль выбранного голоса — в `voice-backend-qwen/`. Для сборки приложения нужен Node.js 22.12 или новее:

```powershell
cd app
npm ci
npm run dist:portable
```

Проверки приложения:

```powershell
cd app
node --test "tests/*.test.js"
```

Код Windows-загрузчика — в `tools/downloader/`. Метаданные готового комплекта и хеши частей — в `release/capri-ready-manifest.json`. Модели и Python не хранятся в Git: готовые файлы опубликованы в релизе. Для отдельной установки голосового модуля из исходников смотри `voice-backend-qwen/README.ru.md`.
