# Капри для рабочего стола

Анимированная спутница для Windows: живёт поверх окон, разговаривает голосом и текстом, реагирует на Spotify, Krita, Minecraft и Space Station 14.

## Скачать и запустить

**Капри уже скачана? [Обновить без повторной загрузки голоса](https://github.com/Numly1/capri-companion/releases/latest/download/Capri-Update.exe)** — примерно 118 МБ вместо нескольких гигабайт. Закрой старую Капри через «Выйти», запусти обновление и нажми «Обновить». Если папка не найдена автоматически, выбери прежнюю готовую папку Капри. Голос, API-ключ и переписка сохранятся. Затем запускай прежний EXE в этой папке.

**В окне «Найти папку» не видно EXE? Это нормально: там показываются только папки.** Выбери саму готовую папку Капри, где рядом лежат приложение, `.tools` и `voice-backend-qwen`; заходить внутрь `.tools` не нужно. Обновлятор версии 13 находит как «Запустить Капри.exe», так и единственный `Capri-Companion-…-win-x64.exe`, сохраняя имя и скачанный голос. Старый номер в имени EXE после обновления может остаться — внутри будет версия 13. При нескольких версиях обновлятор попросит уточнить папку.

**[⬇ Скачать Капри](https://github.com/Numly1/capri-companion/releases/latest/download/Capri-Download.exe)**

Открой скачанный `Capri-Download.exe`. Он сам подготовит готовую папку с голосом и запустит Капри. Команды, Python и отдельные установщики не нужны. При необходимости выбери папку на другом диске кнопкой в окне загрузки.

Первая загрузка — около **4,2 ГБ**. Готовая папка занимает **5,7 ГБ**; во время подготовки нужно примерно **11 ГБ** свободного места. Повторный запуск подготовленной Капри ничего не скачивает: открой `Капри/Запустить Капри.exe`.

## Как пользоваться

- Перетащить: зажми персонажа левой кнопкой мыши.
- Меню и разговор: нажми по Капри правой кнопкой.
- Спрятать или вернуть: `Ctrl + Alt + C`.
- Голос уже включён. Новые фразы на процессоре готовятся с задержкой; записанные и повторные реплики звучат быстрее. У длинных ответов озвучивается короткое начало, а полный ответ остаётся текстом.

Готовые реплики, анимации, реакции на программы и локальное чтение надписей с экрана работают без облачного ИИ. Для свободного диалога один раз подключи доступный API и введи свой ключ в Капри. Ключи и чужая переписка в комплект не входят. Поддержка конкретного сервиса зависит от доступа аккаунта и подключения.

В Spotify видны обложка, исполнитель и прогресс трека. Для Krita есть отдельные похвалы с паузами. Minecraft использует новые события клиентского лога; SS14 — локальное распознавание видимых объявлений. Понимание изображения экрана требует отдельного включения облачного анализа.

## Возможности

Версия 0.4.4-companion.13:

- Исправлена загрузка локального голоса на Windows при нехватке памяти рядом с игрой. Обновление использует прежние скачанные веса и образец Капри; вторую копию модели в комплект не добавляет.
- Исправлен найденный сбой голосового сервера при повторном запросе: генерация остаётся в одном рабочем потоке между репликами.
- Первая новая реплика с загрузкой и подготовкой модели может занимать 1–2 минуты. На этом ПК короткие следующие фразы готовились примерно за 12–18 секунд; более длинная новая реплика — примерно за 46 секунд. Это результаты проверки, а не обещание для любого компьютера: длина фразы, нагрузка и свободная память влияют на скорость. Готовые и повторные фразы берутся из кэша.

- Steam Krita больше не считается игрой из-за папки установки: игровой сон не должен мешать рисованию.
- 48 реплик для Krita, 40 реплик в новом меню «Поддержи меня» и 12 дополнительных тёплых фоновых фраз. В карточке поддержки есть кнопка «Ещё немного поддержки».
- Первая поддержка в Krita — примерно через 45–60 секунд, короткое переключение к референсу не обнуляет отсчёт. Пропущенная из-за занятого интерфейса реплика больше не списывает долгий интервал.

- «В гости»: приглашение другого компьютера через локальную сеть или Radmin VPN, отправка Капри на его экран и возврат домой. Оригинальный анимированный гостевой персонаж, одновременный обмен в обе стороны и автоматический возврат при обрыве связи.
- Исправленный обновлятор узнаёт готовые папки с длинным именем стартового EXE и сохраняет голос.

- Текст удерживается до конца озвучки, точная произносимая фраза и анимация разговора включаются со звуком. Закрытые и заменённые реплики отменяются.
- Карточка Spotify: предыдущий трек, пауза/продолжение, следующий трек; команды направляются только в Spotify. Кнопка ✦ просит Капри потанцевать.
- Valorant: локальное чтение видимых надписей о результате раунда и спайке. LoL: новые события крупных объектов через официальный локальный API. Каждая игра настраивается отдельно, пропущенные события не накапливаются.

- «Экран»: закрепление за выбранным монитором. Временное отключение монитора не сбрасывает выбор.
- «Во время игры»: оставаться рядом, спать или прятаться; задержка и выбор игр задаются отдельно. Автоматический сон заканчивается после переключения из игры.
- Discord Rich Presence: общий публичный Application ID уже встроен. Достаточно включить статус в меню; в карточке используется анимированная Капри. Проверка подключения и повторная попытка доступны из приложения. Игра, просмотр и музыка включаются отдельно; токен аккаунта не нужен.
- «Смотрим вместе · Кинопоиск»: редкие локальные реплики без спойлеров. Автоматический режим ждёт подтверждённого воспроизведения, ручной помогает браузерам без media session. Кадры и сюжет эти реплики не анализируют.
- Дополнительные события SS14: метеориты, ионный шторм, утечка газа, солнечные вспышки, питание; поддержка и передышка из меню, одна отключаемая реплика об ЕРП.

Первый комментарий к просмотру — после двух минут; пауза по умолчанию 12 минут. Сон, игра или разговор подавляют комментарии без отложенной очереди. Код небольшого обновления находится в tools/updater. Новый загрузчик первого запуска использует проверенный голосовой комплект из релиза 8 и добавляет актуальное приложение. Для уже установленной Капри передавай Capri-Update.exe.

## Если Капри почти не реагирует в Krita

1. Обнови приложение через **Capri-Update.exe** и открой прежний EXE. Голосовые модели повторно скачивать не нужно.
2. В меню Капри включи **Krita → «Реагировать на рисование»** и выбери **«Пауза 3 мин»**. Доступны также 2, 5, 12, 20 и 30 минут. Ранее сохранённый интервал не меняется автоматически.
3. Для звука включи **«Озвучивать реплики»**.
4. Верни окно Krita на передний план примерно на минуту. Обычная и Steam-версия распознаются одинаково. Статус можно посмотреть в меню Krita.

Короткое переключение на референс до 45 секунд приостанавливает отсчёт, а не обнуляет его. Время в другом окне не засчитывается; вне Krita похвала не показывается. Если карточка не смогла появиться из-за разговора или занятости, следующая попытка будет не раньше чем через минуту и по свежему состоянию. Старые фразы не ставятся в очередь.

Меню **«Поддержи меня»** даёт поддержку сразу: подбодрить, творческий тупик, неудача, передышка и маленькая победа. В офлайн-переписке можно написать «поддержи меня», «не получается рисовать», «ничего не получается» или «у меня получилось». Готовым репликам ИИ не нужен.

Капри поддерживает процесс и усилия. По одному открытому окну она не видит штрихи, цвета или качество рисунка и не изображает такой анализ. Steam-классификация проверена настоящим встроенным C# на тестовых путях; живой сеанс рисования в Steam Krita на этом ПК не запускался.

## Капри в гостях через Radmin VPN

1. Обновите Капри у обоих через **Capri-Update.exe**.
2. Для разных домов подключите оба компьютера к одной сети [Radmin VPN — инструкция с картинками](https://www.radmin-vpn.com/help/).
3. У первого: меню Капри → «В гости · локальная сеть / Radmin» → пригласить компьютер → выбрать адрес Radmin VPN → скопировать приглашение и отправить подруге.
4. У второго: то же меню → подключиться → вставить код. Код одноразовый, действует 10 минут.
5. «Отправить Капри» переносит её на другой экран. «Вернуть Капри домой» доступно также в меню значка возле часов. Можно обменяться Капри одновременно.

В одной домашней сети можно выбрать «Локальная сеть». Для разных домов нужен Radmin VPN; отдельный Radmin Server не требуется. Визиты включаются вручную, а «Отключить визиты» закрывает соединение и порт. При запросе Windows разреши доступ Капри к нужной сети; отключать брандмауэр целиком не нужно.

Первая версия поддерживает одну пару ПК и по одной гостье на экран. При потере соединения Капри возвращается домой; при зависшем TCP это может занять до 12 секунд. Ручное скрытие персонажа сохраняется. По зашифрованному соединению передаются только имя, поза, направление и размер. Переписка, API-ключи, файлы, экран и голосовые модели не пересылаются. Гостья пока не переносит диалог и голос с другого компьютера.

Пройдены 253 теста приложения, 55 проверок обновлятора, 31 проверка загрузчика, реальные TCP/IPC/WebGL в скрытом Electron и подключение через настоящий Radmin-адрес на одном ПК. Финальный установленный portable EXE проверен двумя новыми репликами подряд, повтором из кэша и настоящим воспроизведением WebAudio с совпадающей подписью. Отдельная HTTP-проверка создала три новые реплики разной длины без падения; Minecraft оставался открыт. Подключение двух физических ПК через Radmin VPN ещё требует пробного запуска у вас.

## Исходники и сборка

Приложение находится в `app/`. Актуальный сервер выбранного голоса поставляется в `app/src/main/companion-qwen-server.py`, подготовка CPU-слоёв — в `app/src/main/companion-voice-cpu.py`; они используют уже установленный комплект из `voice-backend-qwen/` и `.tools/capri-qwen-voice/`. Для сборки приложения нужен Node.js 22.12 или новее:

```powershell
cd app
npm ci
npm run dist:portable
```

Проверки приложения:

```powershell
cd app
node --test "tests/*.test.js"
```

Код Windows-загрузчика — в `tools/downloader/`. Метаданные готового комплекта и хеши частей — в `release/capri-ready-manifest.json`. Модели и Python не хранятся в Git: готовые файлы опубликованы в релизе. Для отдельной установки голосового модуля из исходников смотри `voice-backend-qwen/README.ru.md`.
